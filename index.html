🗺️ Google Maps → 高德地圖

貼上 Google Maps 連結（或直接貼座標），自動將 WGS-84 座標轉成高德用嘅 GCJ-02（火星座標），再生成高德標記／導航連結。唔靠地點名稱搜尋，直接用座標落釘，唔會出現「高德搵唔到同一個名」或者偏幾百米嘅問題。全部喺你部機本地運算，唔使 API Key，唔上傳任何資料。

支援格式：Google 長連結（/place/…、@lat,lon、?q=、query=、!3d…!4d…）、純座標文字。短連結 maps.app.goo.gl 本身唔含座標，要先撳開變成長連結再貼入嚟。

Google Maps（國際版）用全球標準 WGS-84；中國內地依法例，所有內地地圖（高德、騰訊、百度）要用經非線性加密偏移嘅 GCJ-02，同一地點兩套座標可以差 100–700 米。工具會自動判斷：座標喺演算法嘅中國範圍以外（澳洲、歐美、日本等地），原座標直出，唔會亂轉；喺範圍內先做轉換。百度仲要再偏多一層（BD-09），工具亦附送百度連結，一次過搞掂。

轉換演算法：GCJ-02 標準算法（同 GitHub wandergis/coordtransform、googollee/eviltransform 相同公式）。GCJ-02 → WGS-84 為近似逆轉換，誤差約 1–2 米，分享落釘足夠用。
